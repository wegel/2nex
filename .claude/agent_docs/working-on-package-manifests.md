# Working on Package Manifests

## Package Manifest Structure

```yaml
package:
  schema: 1
  name: example
  slug: example
  namespace: libs/system
  version: 1.2.3
  description: short description
  homepage: https://example.org/
  checksum:                        # auto-filled

sources:
- name: example
  url: https://example.org/example-1.2.3.tar.xz
  sha256: placeholder              # use placeholder, build will show correct hash

dependencies:
- name: glibc
  commit: x86_64/pkg/libs/system/glibc/2.39/bundles/dev
# ... more deps

build:
  environment: <env-hash>          # auto-filled
  script: |
    # build commands

bundles:
  dev:
  - dev
  - lib

outputs:                           # auto-generated by --generate-outputs
resolution:                        # auto-generated by --compute-deps
```

## Local File Sources

Some packages use local files (e.g., config.h patches):

```yaml
sources:
- name: example
  url: https://example.org/example-1.2.3.tar.xz
  sha256: ...
- name: config
  file: pkg/desktop/compositor/vwl-config.h
  sha256: 139b9ddc...  # must match file content
```

**When modifying a local file**, update its sha256 in the manifest:

```bash
sha256sum pkg/desktop/compositor/vwl-config.h
# copy the hash to the manifest
```

The build will fail with "SHA256 mismatch" if the hash doesn't match.

## Build Script Patterns

### Autotools
```bash
tar --no-same-owner -xzf /${SOURCE0} -C "${WORK_DIR}" --strip-components=1
cd ${WORK_DIR}

./configure --prefix=/usr

make
make DESTDIR="${OUT_DIR}" install

find ${OUT_DIR} -type f -executable -exec strip --strip-unneeded {} \; 2>/dev/null || true
find ${OUT_DIR} -name '*.a' -exec objcopy --enable-deterministic-archives {} \; 2>/dev/null || true
find "${OUT_DIR}" -exec touch -d "2024-01-01T00:00:00+00:00" {} \;
```

### Meson
```bash
tar --no-same-owner -xf /${SOURCE0} -C "${WORK_DIR}" --strip-components=1
cd ${WORK_DIR}

meson setup build \
  --prefix=/usr \
  --buildtype=release

ninja -C build
DESTDIR="${OUT_DIR}" ninja -C build install

find ${OUT_DIR} -type f -executable -exec strip --strip-unneeded {} \; 2>/dev/null || true
find ${OUT_DIR} -name '*.a' -exec objcopy --enable-deterministic-archives {} \; 2>/dev/null || true
find "${OUT_DIR}" -exec touch -d "2024-01-01T00:00:00+00:00" {} \;
```

## Troubleshooting Patterns

### LTO Linker Errors
Add at start of build script:
```bash
CFLAGS=${CFLAGS/-flto=auto/}
CXXFLAGS=${CXXFLAGS/-flto=auto/}
LDFLAGS=${LDFLAGS/-flto=auto/}
```

### "C compiler cannot create executables"
Check `.nex/tmp/build_rootfs_*/nex/work/config.log` for actual error.
Common causes:
- Missing libz.so.1 → add zlib dependency
- Missing tools → add diffutils, file dependencies

### "C preprocessor cpp fails sanity check"
Usually missing headers. Add:
```yaml
- name: linux-headers
  commit: x86_64/pkg/libs/system/linux-headers/6.4.1/bundles/dev
```
And add `CPP=cpp` to configure command.

### C++ Linking Issues
Add before configure/meson:
```bash
export LDFLAGS="${LDFLAGS} -lstdc++"
```

### Python Build Deps
If package needs Python at build time (e.g., for mako):
```yaml
- name: python3
  commit: x86_64/pkg/dev/lang/python3/3.12.2/bundles/dev
```
